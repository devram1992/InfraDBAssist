# Oracle Performance Troubleshooting

## Initial Checks

Check database load, active sessions, wait events, CPU utilization, memory usage, and long-running SQL statements.

## Session Analysis

Review active sessions to identify sessions consuming significant database resources.

## Wait Event Analysis

Review database wait events to identify potential CPU, I/O, locking, or other resource bottlenecks.

## SQL Analysis

Identify long-running or resource-intensive SQL statements and review their execution characteristics.

## Evidence Required

For detailed performance analysis, collect relevant database metrics, active session information, wait events, and SQL performance information.
